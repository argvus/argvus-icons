# ARGVUS Icons

ARGVUS uses a carefully curated icon theme designed to work cohesively across all applications and system components. The icon set follows modern design principles while maintaining visual consistency throughout the desktop environment.

## Icon Set Overview

The ARGVUS icon theme provides:
- Consistent visual language across all applications
- Support for multiple sizes (16px, 32px, 48px, 64px)
- Scalable SVG icons for crisp rendering at any resolution
- Integration with GTK, Plasma, and standard XDG icon themes

## Installation

Icons are typically installed as part of the main ARGVUS package or can be installed separately:

```bash
pacman -S argvus-icons
```

## Configuration

The icon theme is automatically applied when using ARGVUS. You can also manually set it in:
- ARGVUS Control Center → Appearance → Icons
- Or by editing your GTK configuration
